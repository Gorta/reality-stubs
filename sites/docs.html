Quickstart

Get your first pipeline running in under five minutes. You'll need Node.js 18+ and a Nexus Flow account (the free tier is perfect for this).

1. Install the CLI

npm install -g @nexusflow/cli

2. Authenticate

nexus auth login

3. Initialize a project

nexus init my-first-pipeline

💡 Tip: The CLI scaffolds a working pipeline with a sample source, transform, and sink. You can deploy it immediately with nexus deploy.

4. Deploy

nexus deploy --watch

The --watch flag streams logs to your terminal and redeploys automatically whenever you save a file. Your pipeline will be live in seconds.
