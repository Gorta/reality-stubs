# reality-stubs

A growing collection of static HTML page templates.

🇬🇧 **English** · 🇷🇺 [Русский](#русский)

---

## English

A curated collection of standalone HTML templates — each one a complete, self-contained site with its own design, copy, and micro-interactions. No build step, no external dependencies, no CDN calls. Drop a file into any web server and it just works.

**What's inside**

- Multiple niches: news, e-commerce, local business, travel, SaaS, manufacturing, and more
- Each template is a single `.html` file with inline CSS and JS
- Responsive layouts — mobile, tablet, desktop
- Inline SVG favicons, no external image requests
- Realistic content: company names, addresses, testimonials, product listings
- Works fully offline

**How to use**

1. Pick a file from the `sites/` directory
2. Serve it as `index.html` on any web server
3. Done

**Structure**
```
reality-stubs/
├── list.txt
├── README.md
├── LICENSE
└── sites/
    ├── car-shop.html
    ├── cafe.html
    ├── docs.html
    ├── news.html
    ├── travel-deeper.html
    ├── vertex-forge-industries.html
    └── ... (more added regularly)
```

**Adding your own**

Fork the repo, drop your `.html` file into `sites/`, and add its name to `list.txt`. One file per line.

**License**

MIT — use them however you want.

## Русский

Коллекция самостоятельных HTML-шаблонов. Каждый — полноценный сайт со своим дизайном, текстом и микро-интерактивом. Без сборки, без внешних зависимостей, без обращений к CDN. Кладёшь файл на любой веб-сервер — и он работает.
